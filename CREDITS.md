## Job board APIs (unofficial consumers)

Job Desk reads **public** JSON job-board endpoints. It is **not** affiliated with or endorsed by these companies:

- [Greenhouse](https://www.greenhouse.io) Board API (`boards-api.greenhouse.io`)
- [Ashby](https://www.ashbyhq.com) posting API (`api.ashbyhq.com`)
- [Lever](https://www.lever.co) postings API (`api.lever.co`)

Respect each employer’s terms of use. Do not use this project to spam or auto-submit applications.
