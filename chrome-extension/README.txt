Job Desk fill helper
====================

Fills résumé facts on Greenhouse. Never clicks Submit.

Install
-------
1. On Your details, download job-desk-fill-helper.zip and copy the fill token.
2. Unzip the folder.
3. Chrome → chrome://extensions → Developer mode ON → Load unpacked → select this folder.
4. Open the puzzle-piece toolbar → Job Desk fill helper → paste the token → Save.
   Desk URL defaults to http://localhost:3000. For a Vercel deploy, set desk URL to
   your https://*.vercel.app host (content scripts also match /fill-harness there).
5. Open a Greenhouse posting → tap **Fill from résumé** in the dark bar at the top.
   (If the bar vanishes after a few seconds, update to v1.0.1+ and click Extensions → Reload.)
6. Attach the résumé PDF yourself, check the form, click Submit on the company site.
