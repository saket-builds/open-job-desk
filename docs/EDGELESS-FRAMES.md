## Frame 01 — Start here

**Job Desk**
Open-source personal job desk for Applied AI roles.

1. Discover jobs (Greenhouse / Ashby / Lever)
2. You approve on the desk
3. You apply on the company site

🟢 Sticky: You always click Submit yourself  
🔴 Sticky: No LinkedIn scrape · No auto-submit

Mind map (optional): Discover → Approve → Fill → Submit → Track

---

## Frame 02 — Install in 5 minutes

1. `git clone <repo>`
2. `cd job-desk` → `npm install`
3. `cp .env.example .env.local`
4. `npm run dev`
5. Open http://localhost:3000

🟡 Sticky: Need Node 20+ and Chrome

## Frame 03 — Your details

1. Open **Your details**
2. Replace demo **Jordan Lee** with your packet
3. Save → copy **fill token**
4. Download **job-desk-fill-helper.zip**

🟡 Sticky: Token unlocks your facts — it does not submit forms
