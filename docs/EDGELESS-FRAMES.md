## Visual system

| Element | Use |
| --- | --- |
| Frame 16:9 | One Present slide |
| Edgeless Text | Frame title only |
| Note | ≤1 small card (optional) |
| Sticky green / amber / red | Do / tip / don’t |
| Shapes + connectors | Every process flow |
| Mind map / hub | Frame 01 only |
| Image | Product UI or composed slide PNG |
| Pen | Circle one hotspot on screenshots |

**Banned:** markdown walls, tables as layout, frames that are only a text note.

## AFFiNE build steps

1. Title doc **Job Desk — Visual Guide**
2. Wipe old mega-note
3. Create 8 named 16:9 frames left→right (`01`…`08`)
4. Drop the matching `frame-0N.png` into each frame (full-bleed)
5. Optional: add live stickies/shapes on top of the PNG for extra Edgeless depth
6. Group each frame; hide Present-only blocks from Page mode
7. Present QA → Share → Anyone with the link → **Read only** → copy URL
8. Paste share URL into GUIDE.md IG template
